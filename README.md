# Реализация сверточных нейронных сетей (CNN) для классификации изображений

Учебный проект по классификации жестов на основе датасета Zindi gesture data. Проект включает создание кастомных пайплайнов загрузки данных в PyTorch, ручную сборку архитектуры LeNet-5, применение transfer learning (ResNet18) и реализацию продвинутых методов аугментации (MixUp, CutMix, TTA).

## Ключевые особенности реализации
- Реализован кастомный класс `Dataset` и `DataLoader` в PyTorch для чтения изображений через OpenCV и меток через Pandas.
- Воссоздана архитектура LeNet-5 с использованием слоев `Conv2d`, `Pooling`, `Linear` и `Dropout`.
- Реализован полный цикл обучения (train-validation loop) с функцией потерь Cross Entropy и оценкой по метрике ROC AUC.
- Подключены и дообучены современные бэкбоны (ResNet18 из библиотеки `timm`) с адаптацией классификационной головы под задачу.
- Интегрирована библиотека `albumentations`, реализованы алгоритмы смешивания данных MixUp и CutMix.
- Реализован механизм Test-Time-Augmentation (TTA) для усреднения предсказаний на этапе инференса.

## Стек технологий
- **Язык:** Python 3
- **Библиотеки:** PyTorch (основной фреймворк), OpenCV (чтение изображений), Pandas (работа с метками), Albumentations (аугментации), timm (предобученные модели), Scikit-learn (расчет метрик), Jupyter.

## Что реализовано
**1. Подготовка данных:**
- Очистка датасета от дубликатов и проверка корректности разметки.
- Разделение данных на обучающую и валидационную выборки (33% данных отводится под валидацию).

**2. Архитектура сети:**
- Модульная реализация LeNet-5 с нуля.
- Обертка для загрузки предобученных моделей с заменой финального полносвязного слоя.

**3. Аугментация данных:**
- Применение геометрических и цветовых трансформаций через `albumentations`.
- Программная реализация смешивания выборок (MixUp, CutMix) для повышения обобщающей способности модели и борьбы с переобучением.

**4. Оптимизация и инференс:**
- Настройка цикла обучения с пакетной обработкой (batch processing).
- Реализация TTA для улучшения финальных предсказаний за счет усреднения результатов на аугментированных версиях тестовых изображений.

## Анализ результатов
- Проведено сравнение производительности базовой модели (LeNet-5) и предобученных архитектур (ResNet18) на валидационной выборке.
- Оценено влияние методов аугментации (MixUp, CutMix, TTA) на итоговую метрику ROC AUC. Подтверждено улучшение качества модели при использовании transfer learning и продвинутых аугментаций.

## Структура проекта
- `ml9.ipynb` — основной пайплайн: загрузка данных, предобработка, обучение моделей, расчет метрик и анализ.
- `src/` — модули с реализацией кастомного `Dataset`, архитектур моделей и функций аугментации.
- `ML9_dataset/` — папка для исходных данных (изображения и csv-файлы, не загружаются в репозиторий).
